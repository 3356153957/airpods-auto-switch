# 使用与故障排查

## 设置

- 首次运行，先选择 Windows 已配对的 AirPods，点击“保存设置”。耳机名称必须与 Windows 蓝牙设置中的名称一致；没有找到时可刷新或直接输入。
- 目标耳机、播放确认时间和高级设置中的忽略列表，保存后生效。自动接管、连接通知和收起提醒开关立即生效。
- 关闭自动接管开关会保留当前连接。“断开并暂停”会关闭接管并尝试断开，方便在手机上选择耳机。
- 右键托盘耳机图标打开快捷菜单，点击图标打开控制面板。菜单支持方向键、回车、Esc，点击外部收起。
- 关闭或最小化窗口会收起到托盘，选择托盘“退出程序”才会退出。默认不设置开机启动。
- 收起约 6 秒后切到轻量后台，恢复窗口时保留大小、最大化状态、未保存输入和高级设置展开状态。
- 忽略列表填写进程名，以中英文逗号分隔，不区分大小写。默认忽略 `explorer.exe`、`wallpaper32.exe`、`wallpaper64.exe`。

## 版本与更新

在主界面滚动到“版本与更新”，点击“检测更新”。查询期间按钮暂停使用，结果区会显示已是最新版、发现新版或网络错误；网络错误时可重试或打开发布页。

检查只查询 [本仓库的最新正式 Release](https://github.com/3356153957/airpods-auto-switch/releases/latest)。点击“下载新版本”会打开该 Release 的网页，不在后台下载或覆盖正在运行的程序。

更新步骤：从托盘退出 → 下载并完整解压新版本 → 运行新文件夹中的 `AirPodsSwitch.exe`。旧设置继续使用。不要只替换或移动 exe。

## 接管边界

- 只监测播放设备，不监测麦克风。系统提示音、静音应用、音量为零的应用和忽略列表中的进程不触发接管。
- 连接成功以实际播放输出可用、默认输出切换成功为准；不发送全局播放/暂停按键，不改麦克风选择。
- 耳机离开电脑后，连续播放期间不会反复抢回；静音至少 1 秒后，再次播放才会重新尝试。失败也等待下一轮播放，可手动“立即连接”重试。
- 从开始播放到真正听到耳机声音，还包括 Windows 蓝牙连接耗时。绑定了特定播放设备的应用可能需要改用系统默认输出。
- 关闭开关会阻止后续自动接管；已提交给 Windows 的一次连接请求仍可能完成。
- 耳机需要在附近、从盒中取出并已在 Windows 配对。本程序不更改驱动或系统安全设置。

## 常见问题

**连接不成功**：检查 Windows 蓝牙是否开启、设备名称是否一致、耳机是否在附近；尝试手动连接。某些蓝牙适配器或固件可能不允许从另一台设备接过连接。

**没有右下角提示**：先在高级设置点击“测试通知”，再检查 Windows 通知和勿扰设置。

**检测更新失败**：检查能否打开 GitHub。公共 API 有访问频率限制，稍后重试即可；也可直接从发布页下载。

**窗口关闭后仍占用内存**：程序在托盘工作，约 6 秒后释放界面进程，保留音频监测后台。完全停止请使用托盘“退出程序”。

## 数据

配置、状态和日志位于 `%LOCALAPPDATA%\AirPodsSwitchLocal`，日志最多三份、每份 2 MB。连接日志可能包含耳机名称、蓝牙地址和播放进程名，公开反馈前请移除个人信息。

音频接管在本机运行，不使用原项目的云端交接。只有手动检查更新会请求 GitHub；打开下载页由系统默认浏览器处理。
